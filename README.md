# 🤖 GPT-5 NANO BANANO BOT

Многофункциональный AI Telegram-бот на базе **Python 3.11+** и **aiogram 3**, объединяющий текстовые нейросети, генерацию и редактирование изображений, создание видео, распознавание фотографий, академические и рабочие сервисы, систему подписок и оплаты через **ЮKassa** и **Telegram Stars**.

## 🚀 Основные возможности

### 💬 1. Умный ИИ-чат и работа с текстом (Google Gemini API)
* **Чат по умолчанию**: отправьте любое текстовое сообщение или фото прямо в чат для мгновенного ответа ИИ.
* **Выбор текстовых профилей**:
  * **GPT 5 Luna** — быстрая и доступная модель для повседневных задач (1 токен).
  * **GPT 5 Sol** — сбалансированная модель повышенной точности для сложных задач и кода (2 токена).
  * **GPT 5 Terra** — флагманская аналитическая модель для глубокого разбора (3 токена).
  * **Claude Opus 4.8** — работа со статьями, аналитикой и архитектурой кода (3 токена).
  * **Claude Fable** — креативная модель для сторителлинга и копирайтинга (2 токена).
  * **Grok 4.1** — прямолинейные и точные ответы без воды (2 токена).
* **Управление диалогами**: сохранение контекста беседы, включение/выключение памяти диалога, переключение между несколькими диалогами и очистка истории.
* **Красивое оформление ответов**: автоматическое форматирование ключевых мыслей, заголовков и математических формул в читаемый вид с выделением ***жирным курсивом***.
* **Безлимитный чат с подпиской**: для пользователей с активной подпиской **Premium** общение в текстовом чате полностью бесплатное.

### 🎨 2. Генерация и редактирование изображений (RunBlob API)
* **Nano Banana 🍌**:
  * Выбор модели (`Nano Banana`, `Nano Banana Pro`, `Nano Banana 2`).
  * Настройка формата (`Оригинальный`, `1:1`, `16:9`, `9:16`) и разрешения (`Стандартное`, `2K`, `4K`).
  * Генерация по текстовому описанию (Text-to-Image) и редактирование загруженной фотографии по промпту (Image-to-Image).
* **ChatGPT Images 🔥**:
  * Генерация детализированных картинок и трансформация фотографий по описанию.

### 🎬 3. Генерация видео
* **Kling AI**:
  * Поддержка моделей **Kling 2.5 Turbo Pro** и **Kling 2.1 Master**.
  * Выбор длительности ролика (`5 сек` или `10 сек`).
  * Создание динамичного видео по загруженной фотографии и текстовому описанию движения.
* **Veo 3.1**:
  * Поддержка моделей **Veo 3.1 Fast** и **Veo 3.1 Quality** с выбором формата (`16:9`, `9:16`).
  * Генерация видео по тексту, по 1 фото (анимация кадра), по 2 фото (начальный и конечный кадры) или по 3 фото (референсы).

### 🎓 4. Сервисы для учёбы и работы + Анализ фото
* **📚 Диплом, реферат, эссе**: генерация структурированных студенческих работ (`Эссе`, `Курсовая работа`, `Дипломная работа`, `Реферат`) с автоматической сборкой и отправкой готового файла **Microsoft Word (`.docx`)**.
* **📸 Решение задач по фото**: распознавание условия задачи с фотографии или текста и пошаговое решение с формулами.
* **🔍 Распознавание содержимого картинки**: описание объектов и извлечение текста (OCR) с изображений.
* **🚀 Краткое содержание видео и статей**: структурированная выжимка главных тезисов.
* **✏️ Уникализация текста**: глубокий рерайт с сохранением смысла.
* **🗂 Генерация сценариев**: сценарии для Reels, Shorts, YouTube и презентаций с таймкодами.

### 💳 5. Монетизация, профиль и реферальная система
* **ЮKassa (API v3)**:
  * Прямые платёжные ссылки, встроенные прямо в кнопки оплаты (`Карта РФ`, `СБП`, `Международная карта`).
  * Автоматическая фоновая проверка оплаты + ручная проверка по кнопке `✅ Я оплатил`.
  * Автоматическая поддержка онлайн-чеков по 54-ФЗ (`receipt`).
  * Строгая защита от двойного начисления токенов (`asyncio.Lock` + атомарные транзакции SQLite `BEGIN IMMEDIATE`).
* **Telegram Stars (`XTR`)**: альтернативная оплата подписок и пакетов токенов встроенными звёздами Telegram.
* **Реферальная программа**:
  * Личная ссылка вида `https://t.me/<bot_username>?start=ref_<user_id>`.
  * **+30 бонусных токенов** за каждого приглашённого друга.
  * **30% комиссионных токенов** от всех покупок приглашённого пользователя.
* **Обязательная подписка на канал**: проверка подписки пользователя на Telegram-канал проекта перед использованием функций бота.

## ⚙️ Установка и запуск

### 1. Клонирование репозитория и создание виртуального окружения

```bash
git clone https://github.com/<ваш-логин>/<ваш-репозиторий>.git
cd newBotGPT

# Создание виртуального окружения
python -m venv .venv

# Активация (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Активация (Linux / macOS)
source .venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -U pip
pip install aiogram aiohttp aiosqlite pillow python-docx python-dotenv
```

### 3. Настройка переменных окружения (`.env`)

Создайте в корне проекта файл `.env` и заполните свои ключи:

```env
# Токен вашего Telegram-бота от @BotFather
BOT_TOKEN=your_telegram_bot_token

# Ключи AI-провайдеров
GEMINI_API_KEY=your_google_ai_studio_api_key
RUNBLOB_API_KEY=your_runblob_api_key

# Настройки ЮKassa (из личного кабинета ЮKassa)
YOOKASSA_SHOP_ID=your_yookassa_shop_id
YOOKASSA_SECRET_KEY=your_yookassa_secret_key
YOOKASSA_RETURN_URL=https://t.me/GPT6_NANO_BANANO

# Контакты и каналы (необязательно — имеют значения по умолчанию)
SUPPORT_USERNAME=@Rendix_dev
REQUIRED_CHANNEL_URL=https://t.me/GPT6_NANO_BANANO
REQUIRED_CHANNEL_ID=@GPT6_NANO_BANANO
TASK_CHANNEL_1_URL=https://t.me/GPT6_NANO_BANANO
TASK_CHANNEL_2_URL=https://t.me/GPT6_NANO_BANANO
TASK_CHANNEL_3_URL=https://t.me/GPT6_NANO_BANANO
```

> **Важно для проверки подписки на канал:** добавьте вашего бота в администраторы канала `REQUIRED_CHANNEL_ID` (достаточно базового права на просмотр участников), чтобы Telegram API позволял проверять статус подписки через `get_chat_member`.

### 4. Запуск бота

Из корневой папки проекта выполните:

```bash
python -m app.main
```

## 📋 Команды бота

| Команда | Описание |
| :--- | :--- |
| `/start` | Запуск бота, регистрация пользователя и обработка реферальной ссылки (`?start=ref_ID`) |
| `/profile` | Открытие личного кабинета (баланс токенов, статус подписки, рефералы, поддержка) |
| `/premium` | Меню оформления подписки Premium и докупки пакетов токенов |
| `/check_gemini` | Диагностика подключения к Google Gemini API |
| `/addtokens <число>` | Админ-команда для начисления токенов (доступна только администратору `ADMIN_ID`) |
